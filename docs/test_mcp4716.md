# MCP4716A0 参考电压驱动测试用例

本文档用于验证 `driver/dac_mcp4716/` 在实机上工作正常。驱动依赖 IIC 总线，无法用 cmock 在主机上完成，因此以手工测试为准。

## 1. 测试环境

| 项目 | 要求 |
| --- | --- |
| 硬件 | 目标板，RP2350A，IIC1 上挂 MCP4716A0（地址 0x60） |
| 仪器 | 万用表（或示波器 / 高精度 ADC），分辨率不低于 1 mV |
| 测量点 | MCP4716A0 的 VOUT（即接口缓冲芯片的参考电压输入） |
| 固件 | `build/daplink.uf2` |
| 日志 | UART1 TX（GPIO20），115200 8N1 |

测量前确认：MCP4716A0 供电正常，VREF 引脚实测为 3.3 V（若实测偏离，本文档的期望值需按 `VREF 实测值 × 码值 / 1024` 重新计算）。

## 2. 初始化与状态读取

初始化只通过读命令读取器件状态，不写任何寄存器；MCP4716A0 上电时已自动从 EEPROM 加载码值与配置位。

**方法**

1. 烧录固件，复位目标板。
2. 通过 UART1 观察启动日志。
3. 用逻辑分析仪抓取 IIC1 的 SDA/SCL。
4. 等待 100 ms 后测量 VOUT。

**预期结果**

- 启动日志出现 `mcp4716: <mv>mV (code <code>, pd <pd>)`，数值与 EEPROM 中的设置一致。
- IIC1 上只有一次 6 字节读操作（地址 `0x60`，R/W=1），没有写操作。
- 出厂或从未配置过的板子 EEPROM 为 0 码值、VDD 参考，VOUT 接近 0 V。
- 之前通过 Vendor 命令保存过电压的板子，VOUT 直接恢复该电压。
- 若日志出现 `mcp4716: read failed at 0x60`，说明器件未应答，先排查 IIC 接线、上拉与供电；固件继续启动。

## 3. 参考电压源选择

本项用于确认驱动写入了**外部 VREF 缓冲**配置，而不是器件出厂默认的 VDD 参考。参考电压与增益只在命令 2/3 的配置位中携带。

**方法**

1. 通过 DAP 命令设置 2.5 V（该命令会写入 EEPROM）：`cmsis-dap cmd 0x80 0x19`。
2. 测量 VOUT 并记为 `V1`。
3. 把 `VREF` 引脚的电压源临时改接 2.0 V（或任一明显不同于 3.3 V 的稳定电压），整机断电再上电。
4. 重新测量 VOUT，记为 `V2`。

**预期结果**

- `V2 / V1 ≈ 2.0 / 3.3 ≈ 0.606`。
- 若 `V2 ≈ V1`，说明器件仍在使用 VDD 参考，配置位未生效。
- 若 `V2 ≈ 4 V`（跟随供电轨），说明参考电压选择或增益位写错。
- 测试完成后把 VREF 恢复为 3.3 V。

## 4. 电压线性度

**方法**

1. 在 `app/main.c` 的 `start_task()` 中，把 `dac_mcp4716_init()` 之后临时加入下列代码（`save_to_eeprom = false`，只写易失存储器，不消耗 EEPROM）：

```c
dac_mcp4716_set_mv(825, false);
sleep_ms(50);
dac_mcp4716_set_mv(1650, false);
sleep_ms(50);
dac_mcp4716_set_mv(2475, false);
sleep_ms(50);
dac_mcp4716_set_mv(3300, false);
sleep_ms(50);
```

2. 每次设置后等待至少 50 ms，再读取万用表。

**预期结果**

| 目标 (mV) | 码值 | 理论 VOUT (mV) | 允许范围 (mV) |
| --- | --- | --- | --- |
| 825 | 256 | 825.0 | 805 … 845 |
| 1650 | 512 | 1650.0 | 1630 … 1670 |
| 2475 | 768 | 2475.0 | 2455 … 2495 |
| 3300 | 1023 | 3296.8 | 3277 … 3317 |

- 码值换算关系为 `code = round(mV × 1024 / 3300)`。
- 相邻档位差值应单调递增且接近等间隔（约 825 mV），出现台阶丢失或非单调说明位序错误。
- 允许范围按满量程误差 -1.1 LSB（典型）留出余量；若使用最大误差 -20.5 LSB 判定，误差上限需放宽到约 66 mV。
- `set_mv(0, ...)` 表示进入掉电模式，不作为线性度测试点。

## 5. 同值与 EEPROM 状态去重

**方法**

1. 先调用 `dac_mcp4716_set_mv(825, true)`，确保 EEPROM 中保存的是 825 mV。
2. 连续调用两次 `dac_mcp4716_set_mv(1650, false)`。
3. 用逻辑分析仪或示波器抓取 IIC1 的 SDA/SCL。
4. 再调用一次 `dac_mcp4716_set_mv(1650, true)`，观察 IIC 写入。
5. 再次调用 `dac_mcp4716_set_mv(1650, true)`。

**预期结果**

- 第 2 步的第二次调用**不产生**任何 IIC 波形（易失码值与掉电状态均未变化）。
- 第 4 步会产生一次 3 字节写操作（易失状态与 EEPROM 中的 825 mV 不同，需要保存），随后约 50 ms 内不再有写操作。
- 第 5 步不产生 IIC 波形（易失与非易失状态都已匹配）。

## 5.1 写入命令格式核对

本项用于确认写命令与读命令的字节格式正确。用逻辑分析仪抓取 IIC 波形，按下表逐字节核对。

**初始化阶段**：只有一次读操作。波形为 `START + 0xC1`（7 位地址 `0x60` 左移后加读位），随后器件返回 6 字节；没有写操作。

**运行期设置电压**（`save_to_eeprom = false`，命令 2，3 字节）：

| 目标 | 码值 | 期望字节 | 说明 |
| --- | --- | --- | --- |
| 825 mV | 256 | `0x58 0x40 0x00` | 码值 256<<6 = `0x4000` |
| 1650 mV | 512 | `0x58 0x80 0x00` | 码值 512<<6 = `0x8000` |
| 2475 mV | 768 | `0x58 0xC0 0x00` | 码值 768<<6 = `0xC000` |
| 3300 mV | 1023 | `0x58 0xFF 0xC0` | 码值 1023<<6 = `0xFFC0` |
| 0 mV（关闭） | 当前码值 | `0x5E <code_hi> <code_lo>` | PD 位改为 `11`，首字节 `0x40|0x18|0x06` |

首字节中的 `0x58` = 命令 `010` + REF `11` + PD `00` + GAIN `0`。

**运行期保存电压**（`save_to_eeprom = true`，命令 3，3 字节）：数据与上表相同，首字节改为 `0x78`；关闭时首字节为 `0x7E`。写入后器件进入 EEPROM 编程周期，约 50 ms 内除读命令外的命令都会被忽略。

**读命令**（6 字节）：

| 字节 | 内容 |
| --- | --- |
| 0 | 易失状态/配置：bit7 = RDY/BSY，bit6 = POR，bit5 = 0，bit4:3 = REF，bit2:1 = PD，bit0 = GAIN |
| 1 | 易失码值高字节（b15:b08） |
| 2 | 易失码值低字节（b07:b00） |
| 3 | 非易失状态/配置：同字节 0，但 bit5 = 1 |
| 4 | 非易失码值高字节 |
| 5 | 非易失码值低字节 |

MCP4716 的 10 位码值位于 16 位数据字段的 `b15:b06`。

**配置位序核对**：本驱动按数据手册 Table 4-4 与 Figure 6-5 的位序，把配置位置于首字节 bit4:0，依次为 `REF1 REF0`（bit4:3）、`PD1 PD0`（bit2:1）、`GAIN`（bit0），即正常输出且参考 VREF 缓冲时首字节为 `0x58`/`0x78`。若实际器件采用相反的位序，则输出将不受控；判据是**正常设置电压后 VOUT 必须接近设定值**。

## 6. 掉电模式

**方法**

1. 调用 `dac_mcp4716_set_mv(1650, false)`，记录 VOUT。
2. 调用 `dac_mcp4716_set_mv(0, false)`，记录 VOUT。
3. 调用 `dac_mcp4716_set_mv(1650, false)`，记录 VOUT。
4. 把 `DAC_MCP4716_PD_RESISTOR` 改为 1 或 2，重复步骤 1～3。

**预期结果**

- 步骤 2 后 VOUT 显著下降：掉电模式下输出缓冲关闭，VOUT 经所选下拉电阻对地，接近 0 V。
- 步骤 3 后 VOUT 恢复到步骤 1 的记录值（误差同第 4 节）。
- 掉电期间 `dac_mcp4716_get_mv()` 返回 0。
- 无效的 `DAC_MCP4716_PD_RESISTOR`（0 或大于 3）在编译期报错。

## 7. 总线互斥

**方法**

1. 使上位机持续通过 CDC 串口向 UART0 收发数据（制造 UART 线程负载）。
2. 在另一处（或临时任务中）以 10 ms 间隔反复调用 `dac_mcp4716_set_mv()` 在两个值之间切换（`save_to_eeprom = false`），持续 1 分钟。
3. 人为在持锁状态下阻塞超过 1000 ms，再调用 `dac_mcp4716_set_mv()`。

**预期结果**

- 无 IIC 总线错误日志，无死锁；其他挂在 IIC1 上的器件通信不受影响。
- 步骤 3 中设置调用在锁超时后返回 -1，而不是永久挂起。

## 8. 异常与边界

| 用例 | 方法 | 预期结果 |
| --- | --- | --- |
| 器件不应答 | 断开 MCP4716A0 的 SDA 后复位 | 日志 `mcp4716: read failed at 0x60`，固件继续启动，USB 与 SWD 功能正常 |
| 重复初始化 | 连续调用 `dac_mcp4716_init()` 两次 | 第二次直接返回 0，总线上无额外操作 |
| 未初始化就设置 | 不调用 `dac_mcp4716_init()` 直接调用 `dac_mcp4716_set_mv()` | 返回 -1，总线上无写入 |
| 电压溢出 | 调用 `dac_mcp4716_set_mv(5000, false)` | 钳位到码值 1023，VOUT 约为 3296.8 mV |
| 0 mV | 调用 `dac_mcp4716_set_mv(0, false)` | 进入掉电模式，VOUT 接近 0 V，码值保持 |
| 状态查询 | `dac_mcp4716_get_mv()` | 返回由码值反算的电压；掉电或未初始化时为 0 |

## 8.1 EEPROM 持久化

**方法**

1. 调用 `dac_mcp4716_set_mv(1650, true)`。
2. 等待至少 50 ms（函数内部已等待 EEPROM 写周期）。
3. 整机断电再上电，不修改任何配置，测量 VOUT，并抓取 IIC1 启动波形。

**预期结果**

- 上电后 VOUT 为 1650 mV 附近（器件按 EEPROM 恢复配置与码值）。
- 初始化阶段只读不写，因此 EEPROM 中的设置不会被固件覆盖。
- 启动日志显示 `code 512, pd 0`。
- EEPROM 擦写寿命约 100 万次，不应在运行中高频调用 `save_to_eeprom = true`。

## 9. 回归检查

改动驱动后，除上述用例至少应重跑第 2、4、5、6 节，并确认：

- `cmake --build build` 退出码为 0 且无新增告警。
- RAM 占用无异常增长（链接末尾会打印 FLASH/RAM 占用）。
