# VREF Vendor 命令测试

`module/dap/dap_vendor.c` 的参考电压命令依赖 IIC1 与 MCP4716A0，无法用 cmock 在主机上覆盖，按本文档在实机上验证。

## 1. 测试环境

| 项目 | 要求 |
| --- | --- |
| 硬件 | 目标板，RP2350A，IIC1 上挂 MCP4716A0（地址 0x60） |
| 仪器 | 万用表（或示波器 / 高精度 ADC），分辨率不低于 1 mV |
| 测量点 | MCP4716A0 的 VOUT（接口缓冲芯片的参考电压输入） |
| 上位机 | 支持 `cmsis-dap cmd` 的 OpenOCD |
| 固件 | `build/daplink.uf2` |

测量前确认：MCP4716A0 供电正常，VREF 引脚实测为 3.3 V。

## 2. 命令格式

| 命令 | 请求 | 用途 |
| --- | --- | --- |
| `0x80` | `[0x80, value]` | 设置 VREF，`value` 为 0 或 12…33（0.1 V 单位），并写入 EEPROM |
| `0x81` | `[0x81]` | 读回当前设置 |

响应固定 5 字节：`[cmd, vref_10x, result, mv_lo, mv_hi]`。OpenOCD 打印其中第 1…4 字节，即 `vref_10x result mv_lo mv_hi`。

`result` 取值：`00` 成功，`01` 参数越界且未改动硬件，`02` IIC 访问失败（含器件不应答）。

设置命令通过命令 3 同时更新易失存储器和 EEPROM，需要等待 EEPROM 写周期，约 50 ms 后返回。

## 3. 基本命令

在 OpenOCD 中执行（`adapter serial` 按实际序列号填写，可省略）：

```powershell
openocd -c "adapter driver cmsis-dap; transport select swd" -c "init" `
        -c "cmsis-dap cmd 0x81" `
        -c "cmsis-dap cmd 0x80 0x21" `
        -c "cmsis-dap cmd 0x80 0x19" `
        -c "cmsis-dap cmd 0x81" -c "shutdown"
openocd -c "adapter driver cmsis-dap; transport select swd" -c "adapter speed 2000;init" -c "cmsis-dap cmd 0x80 25" -c "shutdown"
```

| 步骤 | 请求 | 预期打印（`Returned data` 后的 4 字节） | 预期 VOUT |
| --- | --- | --- | --- |
| 读当前值 | `0x81` | 取决于 EEPROM 中的设置 | 同上 |
| 设 3.3 V | `0x80 0x21` | `21 00 e1 0c` | 约 3.297 V |
| 设 2.5 V | `0x80 0x19` | `19 00 c5 09` | 2.5 V ± 20 mV |
| 读回 | `0x81` | `19 00 c5 09` | 同上 |

- `0x21` = 33，即 3.3 V；`0x19` = 25，即 2.5 V。
- 3.3 V 对应码值 1023，理论输出 `3300 × 1023 / 1024 ≈ 3296.8 mV`，驱动按码值反算后返回约 3297 mV（`e1 0c`），详见 `docs/test_mcp4716.md`。
- 2.5 V 对应码值 776，按码值反算约 2501 mV（`c5 09`）。
- 出厂或从未配置过的板子 EEPROM 为 0 码值，读回为 `00 00 00 00`，VOUT 接近 0 V。

## 4. 边界与非法参数

| 用例 | 请求 | 预期打印 | 预期 VOUT |
| --- | --- | --- | --- |
| 下限 1.2 V | `0x80 0x0c` | `0c 00 af 04` | 约 1.199 V |
| 上限 3.3 V | `0x80 0x21` | `21 00 e1 0c` | 约 3.297 V |
| 低于下限 1.1 V | `0x80 0x0b` | `21 01 e1 0c` | 保持 3.3 V |
| 高于上限 3.4 V | `0x80 0x22` | `21 01 e1 0c` | 保持 3.3 V |
| 关闭输出 | `0x80 0x00` | `00 00 00 00` | 接近 0 V |
| 关闭后读回 | `0x81` | `00 00 00 00` | 接近 0 V |
| 关闭后再开启 | `0x80 0x21` | `21 00 e1 0c` | 恢复约 3.297 V |

- 非法值的响应中 `vref_10x`、`mv_lo`、`mv_hi` 仍是当前值，`result` 为 `01`；上表的非法值用例以当前为 3.3 V 为例。
- 0 与 12…33 之外的任何值（1…11、34…255）都不应改变输出，也不应写 EEPROM。
- 关闭输出使用掉电模式，下拉电阻由 `DAC_MCP4716_PD_RESISTOR` 选择（默认 3 = 640 kΩ 对地）。

## 5. EEPROM 持久化

| 用例 | 方法 | 预期 |
| --- | --- | --- |
| 保存电压 | 设置 2.5 V 后给整机断电再上电 | 不发送命令时 VOUT 仍约 2.5 V；`0x81` 返回 `19 00 c5 09` |
| 保存关闭状态 | 设置 0 V 后给整机断电再上电 | VOUT 接近 0 V；`0x81` 返回 `00 00 00 00` |
| 恢复配置 | 关闭状态下重新设置 3.3 V 后断电再上电 | VOUT 恢复约 3.297 V |
| 初始化只读 | 复位后用逻辑分析仪抓取 IIC1 | 启动阶段只有 6 字节读操作，没有写操作 |

- 上电时 MCP4716 自动从 EEPROM 加载码值与配置位，驱动的初始化只读回状态，不会覆盖 EEPROM。
- 每次设置都会写 EEPROM，EEPROM 擦写寿命约 100 万次，不要在高频循环中反复调用设置命令。

## 6. 重复写入与异常

| 用例 | 方法 | 预期 |
| --- | --- | --- |
| 重复写相同值 | 连续两次 `0x80 0x21` | 两次均返回 `21 00 e1 0c`，第二次不产生 IIC 写入 |
| 器件不应答 | 断开 MCP4716A0 的 SDA 后发送命令 | 返回 `result = 02`，固件不复位，USB 与 SWD 功能正常 |
| 参数越界 | 连续发送 `0x80 0x0b` | 每次返回 `result = 01`，EEPROM 与输出均不变 |
| 读写期间调试 | 设置电压后立即执行 SWD 读写 | 调试通道正常，50 ms 的 EEPROM 等待不影响后续命令 |

## 7. 回归检查

- `cmake --build build` 退出码为 0 且无新增告警。
- 命令执行后 SWD/JTAG 调试功能正常，VREF 变化不影响调试通道。
